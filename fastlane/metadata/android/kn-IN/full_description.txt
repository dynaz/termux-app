ನಿಮ್ಮ ಫೋನ್‌ನಿಂದ ಸರ್ವರ್‌ಗಳನ್ನು ನಿರ್ವಹಿಸಿ. TermiNow SSH, RDP ಮತ್ತು SFTP ಮೂಲಕ ರಿಮೋಟ್ ಮೆಷೀನ್‌ಗಳಿಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ ಮತ್ತು Android ನಲ್ಲಿ ಪೂರ್ಣ Linux ಕಮಾಂಡ್ ಲೈನ್ ಚಲಾಯಿಸುತ್ತದೆ — ರೂಟ್ ಅಗತ್ಯವಿಲ್ಲ.

ಹೋಸ್ಟ್‌ಗಳನ್ನು ಒಮ್ಮೆ ಸೇವ್ ಮಾಡಿ — ವಿಳಾಸ, ಪೋರ್ಟ್, ಬಳಕೆದಾರ ಹೆಸರು ಮತ್ತು ಕೀ — ನಂತರ ಒಂದು ಟ್ಯಾಪ್‌ನಲ್ಲಿ ಸಂಪರ್ಕಿಸಿ. PuTTY, FileZilla, SecureCRT, OpenSSH config ಅಥವಾ CSV ನಿಂದ ಸಂಪರ್ಕಗಳನ್ನು ಆಮದು ಮಾಡಿ. ಲೋಕಲ್ ನೆಟ್‌ವರ್ಕ್ ಸ್ಕ್ಯಾನ್ ಮಾಡಿ ಅಥವಾ DigitalOcean ಮತ್ತು AWS ನಿಂದ instance ಆಮದು ಮಾಡಿ.

ಏನು ಮಾಡಬಹುದು:

• ಸೇವ್ ಮಾಡಿದ ಹೋಸ್ಟ್ ಪ್ರೊಫೈಲ್‌ಗಳೊಂದಿಗೆ SSH ಅಥವಾ Mosh ಸಂಪರ್ಕ
• Remote Desktop (RDP) ನಿಂದ Windows ಅಥವಾ Linux ಡೆಸ್ಕ್‌ಟಾಪ್ ತೆರೆಯುವುದು
• SFTP ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಫೈಲ್‌ಗಳನ್ನು ಬ್ರೌಸ್ ಮಾಡುವುದು ಮತ್ತು ವರ್ಗಾಯಿಸುವುದು
• WinRM ಮೂಲಕ Windows ಸರ್ವರ್‌ಗಳಲ್ಲಿ PowerShell ಚಲಾಯಿಸುವುದು
• Bash, Zsh ಮತ್ತು 1000+ ಪ್ಯಾಕೇಜ್‌ಗಳೊಂದಿಗೆ ಪೂರ್ಣ Linux ಟರ್ಮಿನಲ್
• ಮಾರ್ಗದರ್ಶಿ ವಿಜಾರ್ಡ್‌ನಲ್ಲಿ port forwarding ಸೆಟಪ್
• ಕಮಾಂಡ್‌ಗಳನ್ನು Snippets ಆಗಿ ಸೇವ್ ಮಾಡುವುದು, ಆಗಾಗ ಟೆಕ್ಸ್ಟ್ QuickCut ನಲ್ಲಿ
• USB ಮೂಲಕ ಸೀರಿಯಲ್ ಸಾಧನಗಳನ್ನು ಸಂಪರ್ಕಿಸುವುದು
• PuTTY (.ppk) ಮತ್ತು FIDO2 ಸೇರಿದಂತೆ SSH ಕೀಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು
• Ubuntu, Debian ಅಥವಾ Alpine Linux ಪರಿಸರವಾಗಿ ಸ್ಥಾಪಿಸುವುದು
• AI Bridge ನಿಂದ Linux ಪರಿಸರದಲ್ಲಿ Claude Code ಚಲಾಯಿಸುವುದು
• AI ಸಹಾಯಕನನ್ನು ಬಳಸಿ ಚಾಟ್‌ನಲ್ಲಿ ಹೋಸ್ಟ್ ಸೇರಿಸುವುದು ಅಥವಾ ಸಂಪರ್ಕಿಸುವುದು
• ಟರ್ಮಿನಲ್ ಥೀಮ್ ಮತ್ತು ಫಾಂಟ್ ಕಸ್ಟಮೈಸ್ ಮಾಡುವುದು

Premium ಸೇರಿಸುತ್ತದೆ: File Manager, ಬಹು Linux ಪರಿಸರಗಳು, tmux ಸೆಷನ್ ನಿರ್ವಹಣೆ, ಬಾಹ್ಯ AI ಕ್ಲೈಂಟ್‌ಗಳಿಗೆ MCP Bridge ಮತ್ತು Backup & Restore. Google Play ಮೂಲಕ ಮಾಸಿಕ ಅಥವಾ ವಾರ್ಷಿಕ ಚಂದಾ.

ಉಳಿದೆಲ್ಲ — SSH, RDP, SFTP, ಟರ್ಮಿನಲ್, port forwarding, serial, snippets, ಕೀಗಳು, ಮೊದಲ Linux ಪರಿಸರ ಮತ್ತು Claude Code — ಉಚಿತ.

ಮೊದಲ ಪ್ರಾರಂಭದಲ್ಲಿ ಸಣ್ಣ ಮೂಲ ವ್ಯವಸ್ಥೆ ಸ್ಥಾಪಿಸಲಾಗುತ್ತದೆ. 'pkg' ಕಮಾಂಡ್‌ನಿಂದ 1000+ ಪ್ಯಾಕೇಜ್‌ಗಳು ಲಭ್ಯ.
