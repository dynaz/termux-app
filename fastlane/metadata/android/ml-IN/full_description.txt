നിങ്ങളുടെ ഫോണിൽ നിന്ന് സെർവറുകൾ നിയന്ത്രിക്കുക. TermiNow SSH, RDP, SFTP വഴി റിമോട്ട് മെഷീനുകളിലേക്ക് കണക്റ്റ് ചെയ്യുകയും Android-ൽ പൂർണ്ണ Linux കമാൻഡ് ലൈൻ പ്രവർത്തിപ്പിക്കുകയും ചെയ്യുന്നു — റൂട്ട് ആവശ്യമില്ല.

ഹോസ്റ്റുകൾ ഒരിക്കൽ സേവ് ചെയ്യുക — വിലാസം, പോർട്ട്, യൂസർനെയിം, കീ — പിന്നെ ഒരു ടാപ്പിൽ കണക്റ്റ് ചെയ്യുക. PuTTY, FileZilla, SecureCRT, OpenSSH config അല്ലെങ്കിൽ CSV-യിൽ നിന്ന് കണക്ഷനുകൾ ഇമ്പോർട്ട് ചെയ്യുക. ലോക്കൽ നെറ്റ്‌വർക്ക് സ്കാൻ ചെയ്യുക അല്ലെങ്കിൽ DigitalOcean, AWS-ൽ നിന്ന് instance ഇമ്പോർട്ട് ചെയ്യുക.

എന്ത് ചെയ്യാം:

• സേവ് ചെയ്ത ഹോസ്റ്റ് പ്രൊഫൈലുകളോടെ SSH അല്ലെങ്കിൽ Mosh കണക്ഷൻ
• Remote Desktop (RDP) ഉപയോഗിച്ച് Windows അല്ലെങ്കിൽ Linux ഡെസ്‌ക്‌ടോപ്പ് തുറക്കൽ
• SFTP ബ്രൗസറിൽ ഫയലുകൾ ബ്രൗസ് ചെയ്യലും കൈമാറ്റവും
• WinRM വഴി Windows സെർവറുകളിൽ PowerShell പ്രവർത്തിപ്പിക്കൽ
• Bash, Zsh, 1000+ പാക്കേജുകളോടെ പൂർണ്ണ Linux ടെർമിനൽ
• ഗൈഡഡ് വിസാർഡിൽ port forwarding സെറ്റപ്പ്
• കമാൻഡുകൾ Snippets ആയി സേവ് ചെയ്യൽ, ഇടയ്ക്കിടെയുള്ള ടെക്‌സ്‌റ്റ് QuickCut-ൽ
• USB വഴി സീരിയൽ ഉപകരണങ്ങൾ കണക്റ്റ് ചെയ്യൽ
• PuTTY (.ppk), FIDO2 ഉൾപ്പെടെ SSH കീകൾ നിയന്ത്രിക്കൽ
• Ubuntu, Debian അല്ലെങ്കിൽ Alpine Linux എൻവയൺമെന്റായി ഇൻസ്‌റ്റാൾ ചെയ്യൽ
• AI Bridge ഉപയോഗിച്ച് Linux എൻവയൺമെന്റിൽ Claude Code പ്രവർത്തിപ്പിക്കൽ
• AI അസിസ്റ്റന്റ് ഉപയോഗിച്ച് ചാറ്റിൽ ഹോസ്റ്റ് ചേർക്കൽ അല്ലെങ്കിൽ കണക്റ്റ് ചെയ്യൽ
• ടെർമിനലിന്റെ തീം, ഫോണ്ട് ഇഷ്ടാനുസൃതമാക്കൽ

Premium ചേർക്കുന്നു: File Manager, ഒന്നിലധികം Linux എൻവയൺമെന്റുകൾ, tmux സെഷൻ മാനേജ്‌മെന്റ്, ബാഹ്യ AI ക്ലയന്റുകൾക്കുള്ള MCP Bridge, Backup & Restore. Google Play വഴി പ്രതിമാസ അല്ലെങ്കിൽ വാർഷിക സബ്‌സ്‌ക്രിപ്ഷൻ.

മറ്റെല്ലാം — SSH, RDP, SFTP, ടെർമിനൽ, port forwarding, serial, snippets, കീകൾ, ആദ്യ Linux എൻവയൺമെന്റ്, Claude Code — സൗജന്യമാണ്.

ആദ്യ തുടക്കത്തിൽ ചെറിയ ബേസ് സിസ്റ്റം ഇൻസ്‌റ്റാൾ ചെയ്യുന്നു. 'pkg' കമാൻഡ് ഉപയോഗിച്ച് 1000+ പാക്കേജുകൾ ലഭ്യമാണ്.
