أدِر خوادمك من هاتفك. يتصل TermiNow بالأجهزة البعيدة عبر SSH و RDP و SFTP، ويشغّل سطر أوامر لينكس كامل على أندرويد — بدون الحاجة إلى صلاحيات الروت.

احفظ مضيفيك مرة واحدة — العنوان والمنفذ واسم المستخدم والمفتاح — ثم اتصل بلمسة واحدة. استورد الاتصالات من PuTTY أو FileZilla أو SecureCRT أو OpenSSH config أو CSV، للانتقال من برنامج سطح المكتب بدون إعادة إدخال كل شيء. افحص شبكتك المحلية للعثور على الأجهزة، أو استورد instances من DigitalOcean و AWS.

ما يمكنك فعله:

• الاتصال عبر SSH أو Mosh مع حفظ ملفات تعريف المضيفين ومصادقة المفاتيح
• فتح سطح مكتب Windows أو Linux عبر Remote Desktop (RDP)
• تصفح ونقل الملفات عبر متصفح SFTP
• تشغيل PowerShell على خوادم Windows عبر WinRM
• استخدام طرفية لينكس كاملة مع Bash و Zsh وأكثر من 1000 حزمة
• إعداد توجيه المنافذ — محلي أو بعيد أو ديناميكي — بمعالج إرشادي
• حفظ الأوامر كقصاصات والنصوص المتكررة في QuickCut
• الاتصال بأجهزة تسلسلية عبر USB
• إدارة مفاتيح SSH بما فيها PuTTY (.ppk) و FIDO2
• تثبيت Ubuntu أو Debian أو Alpine كبيئة لينكس على الجهاز
• تشغيل Claude Code في بيئة لينكس عبر AI Bridge
• استخدام مساعد AI لإضافة المضيفين أو الاتصال عبر المحادثة
• تخصيص سمة الطرفية والخط

يضيف Premium مدير الملفات (تصفح تخزين الجهاز ومضيفي SFTP مع قائمة انتظار النقل)، وبيئات لينكس متعددة، وإدارة جلسات tmux، وجسر MCP لعملاء AI الخارجيين، والنسخ الاحتياطي والاستعادة. اشتراك شهري أو سنوي عبر Google Play.

كل شيء آخر — SSH و RDP و SFTP والطرفية وتوجيه المنافذ والمنفذ التسلسلي والقصاصات والمفاتيح وأول بيئة لينكس و Claude Code — مجاني.

عند التشغيل الأول يتم تثبيت نظام أساسي صغير. أكثر من 1000 حزمة إضافية متاحة عبر أمر 'pkg'.
