נהלו את השרתים שלכם מהטלפון. TermiNow מתחבר למכונות מרוחקות דרך SSH, RDP ו-SFTP ומריץ שורת פקודה מלאה של לינוקס באנדרואיד — ללא root.

שמרו מארחים פעם אחת — כתובת, פורט, שם משתמש ומפתח — ואז התחברו בנגיעה אחת. ייבאו חיבורים מ-PuTTY, FileZilla, SecureCRT, OpenSSH config או CSV. סרקו את הרשת המקומית או ייבאו instances מ-DigitalOcean ו-AWS.

מה אפשר לעשות:

• התחברות ב-SSH או Mosh עם פרופילי מארח שמורים ואימות מפתח
• פתיחת שולחן עבודה של Windows או Linux עם Remote Desktop (RDP)
• עיון והעברת קבצים בדפדפן SFTP
• הרצת PowerShell בשרתי Windows דרך WinRM
• טרמינל לינוקס מלא עם Bash, Zsh ומעל 1000 חבילות
• הגדרת העברת פורטים — מקומית, מרוחקת או דינמית — באשף מונחה
• שמירת פקודות כקטעי קוד וטקסט שכיח ב-QuickCut
• חיבור מכשירים סריאליים ב-USB
• ניהול מפתחות SSH כולל PuTTY (.ppk) ו-FIDO2
• התקנת Ubuntu, Debian או Alpine כסביבת לינוקס
• הרצת Claude Code בסביבת לינוקס עם AI Bridge
• שימוש בעוזר AI להוספת מארחים או התחברות בצ'אט
• התאמה אישית של ערכת נושא וגופן הטרמינל

Premium מוסיף מנהל קבצים, מספר סביבות לינוקס, ניהול הפעלות tmux, MCP Bridge ללקוחות AI חיצוניים וגיבוי ושחזור. מנוי חודשי או שנתי דרך Google Play.

כל השאר — SSH, RDP, SFTP, טרמינל, העברת פורטים, סריאלי, קטעי קוד, מפתחות, סביבת לינוקס ראשונה ו-Claude Code — חינם.

בהפעלה ראשונה מותקנת מערכת בסיס קטנה. מעל 1000 חבילות נוספות זמינות בפקודה 'pkg'.
