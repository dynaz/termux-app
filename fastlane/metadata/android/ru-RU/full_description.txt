Управляйте серверами с телефона. TermiNow подключается к удалённым машинам по SSH, RDP и SFTP и запускает полноценную командную строку Linux на Android — без root.

Сохраните хосты один раз — адрес, порт, имя пользователя и ключ — и подключайтесь одним касанием. Импортируйте подключения из PuTTY, FileZilla, SecureCRT, OpenSSH config или CSV. Сканируйте локальную сеть или импортируйте инстансы из DigitalOcean и AWS.

Что можно делать:

• Подключаться по SSH или Mosh с сохранёнными профилями и аутентификацией по ключу
• Открывать рабочий стол Windows или Linux через Remote Desktop (RDP)
• Просматривать и передавать файлы через SFTP-браузер
• Запускать PowerShell на серверах Windows через WinRM
• Использовать полноценный Linux-терминал с Bash, Zsh и 1000+ пакетами
• Настраивать проброс портов — локальный, удалённый или динамический — с помощью мастера
• Сохранять команды как сниппеты, а частый текст — в QuickCut
• Подключать последовательные устройства через USB
• Управлять SSH-ключами, включая PuTTY (.ppk) и FIDO2
• Устанавливать Ubuntu, Debian или Alpine как Linux-окружение
• Запускать Claude Code в Linux-окружении через AI Bridge
• Использовать ИИ-ассистент для добавления хостов или подключения через чат
• Настраивать тему и шрифт терминала

Premium добавляет Файловый менеджер (просмотр хранилища устройства и SFTP-хостов с очередью передачи), несколько Linux-окружений, управление tmux-сессиями, MCP Bridge для внешних ИИ-клиентов и Резервное копирование. Ежемесячная или годовая подписка через Google Play.

Всё остальное — SSH, RDP, SFTP, терминал, проброс портов, последовательный порт, сниппеты, ключи, первое Linux-окружение и Claude Code — бесплатно.

При первом запуске устанавливается небольшая базовая система. Более 1000 дополнительных пакетов доступны через команду 'pkg'.
