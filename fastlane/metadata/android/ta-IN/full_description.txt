உங்கள் தொலைபேசியிலிருந்து சேவையகங்களை நிர்வகியுங்கள். TermiNow SSH, RDP மற்றும் SFTP வழியாக தொலைநிலை கணினிகளுடன் இணைகிறது மற்றும் Android-இல் முழு Linux கட்டளை வரியை இயக்குகிறது — ரூட் தேவையில்லை.

ஹோஸ்ட்களை ஒரு முறை சேமியுங்கள் — முகவரி, போர்ட், பயனர்பெயர் மற்றும் கீ — பின்னர் ஒரே தட்டலில் இணையுங்கள். PuTTY, FileZilla, SecureCRT, OpenSSH config அல்லது CSV-யிலிருந்து இணைப்புகளை இறக்குமதி செய்யுங்கள். உள்ளூர் நெட்வொர்க்கை ஸ்கேன் செய்யுங்கள் அல்லது DigitalOcean மற்றும் AWS-யிலிருந்து instance இறக்குமதி செய்யுங்கள்.

என்ன செய்யலாம்:

• சேமிக்கப்பட்ட ஹோஸ்ட் சுயவிவரங்கள் மற்றும் கீ அங்கீகாரத்துடன் SSH அல்லது Mosh இணைப்பு
• Remote Desktop (RDP) மூலம் Windows அல்லது Linux டெஸ்க்டாப் திறத்தல்
• SFTP உலாவியில் கோப்புகளை உலாவுதல் மற்றும் பரிமாற்றம்
• WinRM மூலம் Windows சேவையகங்களில் PowerShell இயக்குதல்
• Bash, Zsh மற்றும் 1000+ தொகுப்புகளுடன் முழு Linux முனையம்
• வழிகாட்டப்பட்ட வழிகாட்டியில் port forwarding அமைத்தல்
• கட்டளைகளை Snippets ஆக சேமித்தல், அடிக்கடி உரையை QuickCut-இல் வைத்தல்
• USB வழியாக சீரியல் சாதனங்களை இணைத்தல்
• PuTTY (.ppk) மற்றும் FIDO2 உட்பட SSH விசைகளை நிர்வகித்தல்
• சாதனத்தில் Ubuntu, Debian அல்லது Alpine Linux சூழலாக நிறுவுதல்
• AI Bridge மூலம் Linux சூழலில் Claude Code இயக்குதல்
• AI உதவியாளர் மூலம் சாட்டில் ஹோஸ்ட் சேர்த்தல் அல்லது இணைதல்
• முனையத்தின் தீம் மற்றும் எழுத்துரு தனிப்பயனாக்குதல்

Premium சேர்க்கிறது: File Manager, பல Linux சூழல்கள், tmux அமர்வு நிர்வாகம், வெளிப்புற AI வாடிக்கையாளர்களுக்கான MCP Bridge மற்றும் Backup & Restore. Google Play வழியாக மாதாந்திர அல்லது வருடாந்திர சந்தா.

மற்ற அனைத்தும் — SSH, RDP, SFTP, முனையம், port forwarding, serial, snippets, விசைகள், முதல் Linux சூழல் மற்றும் Claude Code — இலவசம்.

முதல் தொடக்கத்தில் சிறிய அடிப்படை அமைப்பு நிறுவப்படும். 'pkg' கட்டளை மூலம் 1000+ கூடுதல் தொகுப்புகள் கிடைக்கும்.
