휴대폰에서 서버를 관리하세요. TermiNow는 SSH, RDP, SFTP로 원격 머신에 연결하고 Android에서 완전한 Linux 명령줄을 실행합니다 — 루팅 불필요.

호스트를 한 번 저장하세요 — 주소, 포트, 사용자 이름, 키 — 그런 다음 한 번 탭으로 연결합니다. PuTTY, FileZilla, SecureCRT, OpenSSH config 또는 CSV에서 연결을 가져올 수 있습니다. 로컬 네트워크를 스캔하거나 DigitalOcean과 AWS에서 인스턴스를 가져오세요.

할 수 있는 것:

• 저장된 호스트 프로필과 키 인증으로 SSH 또는 Mosh 연결
• 원격 데스크톱(RDP)으로 Windows 또는 Linux 데스크톱 열기
• SFTP 브라우저로 파일 탐색 및 전송
• WinRM으로 Windows 서버에서 PowerShell 실행
• Bash, Zsh 및 1000개 이상의 패키지가 있는 완전한 Linux 터미널
• 안내 마법사로 포트 포워딩 설정 — 로컬, 원격 또는 동적
• 명령어를 스니펫으로 저장하고 자주 쓰는 텍스트를 QuickCut에 보관
• USB로 시리얼 장치 연결
• PuTTY (.ppk) 및 FIDO2를 포함한 SSH 키 관리
• 장치에 Ubuntu, Debian 또는 Alpine을 Linux 환경으로 설치
• AI Bridge로 Linux 환경에서 Claude Code 실행
• AI 어시스턴트로 채팅을 통해 호스트 추가 또는 연결
• 터미널 테마와 글꼴 사용자 지정
