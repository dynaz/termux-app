# TermiNow Play Store Screenshot Brief

The current 4 screenshots are from upstream Termux and must be replaced.
They show "Welcome to Termux!", "Hello World from Termux!", nmap, and NetHack —
none of which reflect TermiNow branding or features.

## Required screenshots (1080x2340 or 1080x1920, JPEG or PNG)

Capture from the real app on a device or emulator.
Mask all passwords, tokens, private keys and real server addresses.

### Recommended order (8 screenshots)

1. **Hosts list** — the main screen with several saved SSH hosts, showing
   the TermiNow home with groups and quick-connect cards.
   Caption EN: "All your servers in one place"
   Caption TH: "เซิร์ฟเวอร์ทั้งหมดในที่เดียว"

2. **SSH terminal** — an active SSH session connected to a host, showing
   the TermiNow terminal with the extra-key bar.
   Caption EN: "Connect with one tap"
   Caption TH: "เชื่อมต่อด้วยแตะเพียงครั้งเดียว"

3. **RDP session** — a Remote Desktop session showing a Windows or Linux
   desktop on the phone.
   Caption EN: "Remote Desktop from your phone"
   Caption TH: "เดสก์ท็อประยะไกลจากมือถือ"

4. **SFTP browser** — the SFTP file browser connected to a host, showing
   files and folders with transfer options.
   Caption EN: "Browse and transfer files with SFTP"
   Caption TH: "เรียกดูและถ่ายโอนไฟล์ด้วย SFTP"

5. **Linux environment** — Ubuntu running in TermiNow, showing the
   installed environments list or an Ubuntu terminal.
   Caption EN: "Run Ubuntu, Debian or Alpine"
   Caption TH: "รัน Ubuntu, Debian หรือ Alpine"

6. **Quick Import** — the import preview screen showing hosts imported
   from PuTTY, FileZilla or OpenSSH config.
   Caption EN: "Import from PuTTY, FileZilla, SecureCRT"
   Caption TH: "นำเข้าจาก PuTTY, FileZilla, SecureCRT"

7. **AI Assistant** — the AI chat screen adding a host or connecting,
   showing Thai or English conversation.
   Caption EN: "AI Assistant helps you manage hosts"
   Caption TH: "AI Assistant ช่วยจัดการโฮสต์"

8. **Port forwarding / Snippets** — the port forwarding wizard or the
   snippets list, showing productivity features.
   Caption EN: "Port forwarding and command snippets"
   Caption TH: "Port forwarding และ Snippets"
