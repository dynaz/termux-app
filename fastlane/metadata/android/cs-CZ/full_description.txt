Spravujte servery z telefonu. TermiNow se připojuje ke vzdáleným strojům přes SSH, RDP a SFTP a spouští plnohodnotný příkazový řádek Linuxu na Androidu — bez nutnosti rootu.

Uložte hostitele jednou — adresu, port, uživatelské jméno a klíč — a pak se připojte jedním klepnutím. Importujte připojení z PuTTY, FileZilla, SecureCRT, OpenSSH configu nebo CSV. Skenujte místní síť nebo importujte instance z DigitalOcean a AWS.

Co můžete dělat:

• Připojení přes SSH nebo Mosh s uloženými profily a klíčovou autentizací
• Otevření plochy Windows nebo Linuxu přes Remote Desktop (RDP)
• Procházení a přenos souborů přes SFTP prohlížeč
• Spouštění PowerShellu na Windows serverech přes WinRM
• Plnohodnotný Linux terminál s Bash, Zsh a 1000+ balíčky
• Nastavení přesměrování portů — místní, vzdálené nebo dynamické — v průvodci
• Ukládání příkazů jako Úryvky a častého textu do QuickCut
• Připojení sériových zařízení přes USB
• Správa SSH klíčů včetně PuTTY (.ppk) a FIDO2
• Instalace Ubuntu, Debian nebo Alpine jako Linux prostředí
• Spuštění Claude Code v Linux prostředí přes AI Bridge
• AI asistent pro přidání hostitelů nebo připojení chatem
• Přizpůsobení motivu a písma terminálu
