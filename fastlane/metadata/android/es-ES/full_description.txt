Gestione sus servidores desde el teléfono. TermiNow se conecta a máquinas remotas mediante SSH, RDP y SFTP, y ejecuta una línea de comandos Linux completa en Android — sin root.

Guarde sus hosts una vez — dirección, puerto, usuario y clave — y conéctese con un toque. Importe conexiones de PuTTY, FileZilla, SecureCRT, OpenSSH config o CSV. Escanee su red local o importe instancias de DigitalOcean y AWS.

Qué puede hacer:

• Conectarse por SSH o Mosh con perfiles guardados y autenticación por clave
• Abrir un escritorio Windows o Linux con Escritorio Remoto (RDP)
• Navegar y transferir archivos con el navegador SFTP
• Ejecutar PowerShell en servidores Windows por WinRM
• Usar un terminal Linux completo con Bash, Zsh y más de 1000 paquetes
• Configurar reenvío de puertos — local, remoto o dinámico — con asistente
• Guardar comandos como Fragmentos y texto frecuente en QuickCut
• Conectar dispositivos serie por USB
• Gestionar claves SSH, incluidas PuTTY (.ppk) y FIDO2
• Instalar Ubuntu, Debian o Alpine como entorno Linux
• Ejecutar Claude Code en el entorno Linux con AI Bridge
• Usar el asistente de IA para añadir hosts o conectarse por chat
• Personalizar el tema y la fuente del terminal

Premium añade el Gestor de archivos, varios entornos Linux, gestión de sesiones tmux, MCP Bridge para clientes de IA externos y Copia de seguridad y restauración. Suscripción mensual o anual por Google Play.

Todo lo demás — SSH, RDP, SFTP, terminal, reenvío de puertos, serie, fragmentos, claves, el primer entorno Linux y Claude Code — es gratuito.

Al iniciar por primera vez se instala un pequeño sistema base. Más de 1000 paquetes adicionales disponibles con el comando 'pkg'.
