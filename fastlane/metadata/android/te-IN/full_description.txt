మీ ఫోన్ నుండి సర్వర్‌లను నిర్వహించండి. TermiNow SSH, RDP మరియు SFTP ద్వారా రిమోట్ మెషీన్‌లకు కనెక్ట్ అవుతుంది మరియు Android లో పూర్తి Linux కమాండ్ లైన్ రన్ చేస్తుంది — రూట్ అవసరం లేదు.

హోస్ట్‌లను ఒకసారి సేవ్ చేయండి — అడ్రస్, పోర్ట్, యూజర్‌నేమ్ మరియు కీ — తర్వాత ఒక్క ట్యాప్‌తో కనెక్ట్ అవ్వండి. PuTTY, FileZilla, SecureCRT, OpenSSH config లేదా CSV నుండి కనెక్షన్‌లను ఇంపోర్ట్ చేయండి. లోకల్ నెట్‌వర్క్ స్కాన్ చేయండి లేదా DigitalOcean మరియు AWS నుండి instance ఇంపోర్ట్ చేయండి.

ఏమి చేయవచ్చు:

• సేవ్ చేసిన హోస్ట్ ప్రొఫైల్‌లతో SSH లేదా Mosh కనెక్షన్
• Remote Desktop (RDP) తో Windows లేదా Linux డెస్క్‌టాప్ ఓపెన్ చేయడం
• SFTP బ్రౌజర్‌తో ఫైల్‌లు బ్రౌజ్ మరియు ట్రాన్స్‌ఫర్
• WinRM ద్వారా Windows సర్వర్‌లలో PowerShell రన్ చేయడం
• Bash, Zsh మరియు 1000+ ప్యాకేజీలతో పూర్తి Linux టెర్మినల్
• గైడెడ్ విజార్డ్‌తో port forwarding సెటప్
• కమాండ్‌లను Snippets గా సేవ్ చేయడం, తరచుగా టెక్స్ట్ QuickCut లో
• USB ద్వారా సీరియల్ డివైస్‌లకు కనెక్ట్
• PuTTY (.ppk) మరియు FIDO2 తో SSH కీలు నిర్వహణ
• Ubuntu, Debian లేదా Alpine Linux ఎన్విరాన్‌మెంట్‌గా ఇన్‌స్టాల్
• AI Bridge తో Linux ఎన్విరాన్‌మెంట్‌లో Claude Code రన్
• AI అసిస్టెంట్‌తో చాట్‌లో హోస్ట్ జోడించడం లేదా కనెక్ట్ అవ్వడం
• టెర్మినల్ థీమ్ మరియు ఫాంట్ కస్టమైజ్

Premium జోడిస్తుంది: File Manager, బహుళ Linux ఎన్విరాన్‌మెంట్‌లు, tmux సెషన్ మేనేజ్‌మెంట్, బాహ్య AI క్లయింట్‌లకు MCP Bridge మరియు Backup & Restore. Google Play ద్వారా నెలవారీ లేదా వార్షిక సబ్‌స్క్రిప్షన్.

మిగతా అన్నీ — SSH, RDP, SFTP, టెర్మినల్, port forwarding, serial, snippets, కీలు, మొదటి Linux ఎన్విరాన్‌మెంట్ మరియు Claude Code — ఉచితం.

మొదటి ప్రారంభంలో చిన్న బేస్ సిస్టమ్ ఇన్‌స్టాల్ అవుతుంది. 'pkg' కమాండ్‌తో 1000+ అదనపు ప్యాకేజీలు అందుబాటులో ఉన్నాయి.
