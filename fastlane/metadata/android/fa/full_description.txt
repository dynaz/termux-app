سرورهای خود را از گوشی مدیریت کنید. TermiNow از طریق SSH، RDP و SFTP به ماشین‌های راه دور متصل می‌شود و خط فرمان کامل لینوکس را روی اندروید اجرا می‌کند — بدون نیاز به روت.

میزبان‌ها را یک بار ذخیره کنید — آدرس، پورت، نام کاربری و کلید — سپس با یک لمس متصل شوید. اتصالات را از PuTTY، FileZilla، SecureCRT، OpenSSH config یا CSV وارد کنید. شبکه محلی را اسکن کنید یا instance از DigitalOcean و AWS وارد کنید.

کارهایی که می‌توانید انجام دهید:

• اتصال از طریق SSH یا Mosh با پروفایل‌های میزبان ذخیره شده و احراز هویت کلید
• باز کردن دسکتاپ Windows یا Linux با Remote Desktop (RDP)
• مرور و انتقال فایل با مرورگر SFTP
• اجرای PowerShell روی سرورهای Windows از طریق WinRM
• استفاده از ترمینال کامل لینوکس با Bash، Zsh و بیش از ۱۰۰۰ بسته
• تنظیم ارسال پورت — محلی، راه دور یا پویا — با جادوگر راهنما
• ذخیره دستورات به عنوان Snippet و متن مکرر در QuickCut
• اتصال دستگاه‌های سریال از طریق USB
• مدیریت کلیدهای SSH از جمله PuTTY (.ppk) و FIDO2
• نصب Ubuntu، Debian یا Alpine به عنوان محیط لینوکس
• اجرای Claude Code در محیط لینوکس با AI Bridge
• استفاده از دستیار AI برای افزودن میزبان یا اتصال از طریق چت
• سفارشی‌سازی تم و فونت ترمینال

Premium اضافه می‌کند: مدیریت فایل، چند محیط لینوکس، مدیریت جلسات tmux، MCP Bridge برای کلاینت‌های AI خارجی و پشتیبان‌گیری و بازیابی. اشتراک ماهانه یا سالانه از طریق Google Play.

همه چیز دیگر — SSH، RDP، SFTP، ترمینال، ارسال پورت، سریال، snippet، کلیدها، اولین محیط لینوکس و Claude Code — رایگان است.

در اولین اجرا یک سیستم پایه کوچک نصب می‌شود. بیش از ۱۰۰۰ بسته اضافی با دستور 'pkg' در دسترس است.
