用手机管理你的服务器。TermiNow 通过 SSH、RDP 和 SFTP 连接远程设备，在 Android 上运行完整的 Linux 命令行——无需 root。

只需保存一次主机信息——地址、端口、用户名和密钥——然后一键连接。从 PuTTY、FileZilla、SecureCRT、OpenSSH config 或 CSV 导入连接，从桌面客户端迁移无需重新输入。扫描本地网络发现设备，或从 DigitalOcean 和 AWS 导入实例。

功能一览：

• 使用保存的主机配置和密钥认证通过 SSH 或 Mosh 连接
• 通过远程桌面 (RDP) 打开 Windows 或 Linux 桌面
• 使用 SFTP 浏览器浏览和传输文件
• 通过 WinRM 在 Windows 服务器上运行 PowerShell
• 使用完整的 Linux 终端，包含 Bash、Zsh 和 1000+ 可安装软件包
• 通过引导向导设置端口转发——本地、远程或动态
• 将命令保存为 Snippets，常用文本保存在 QuickCut 中
• 通过 USB 连接串口设备
• 管理 SSH 密钥，包括 PuTTY (.ppk) 和 FIDO2 安全密钥
• 在设备上安装 Ubuntu、Debian 或 Alpine 作为 Linux 环境
• 通过 AI Bridge 在 Linux 环境中运行 Claude Code
• 使用 AI 助手通过对话添加主机或连接
• 自定义终端主题和字体

Premium 增加文件管理器（浏览设备存储和 SFTP 主机，带传输队列）、多个 Linux 环境、tmux 会话管理、用于外部 AI 客户端的 MCP Bridge 以及备份和恢复功能。通过 Google Play 按月或按年订阅。

其他所有功能——SSH、RDP、SFTP、终端、端口转发、串口、代码片段、密钥、第一个 Linux 环境和 Claude Code——均免费。
