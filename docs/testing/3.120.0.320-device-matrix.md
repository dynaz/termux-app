# 3.120.0.320 — Device Test Matrix

On-device verification for internal build **3.120.0.320** (arm64). Covers the Packet Capture
crash/freeze/state work and the SAF `.pcap` import (319–320), plus the Security Tools bottom sheet,
swipe, search and environment chip. **All of this is JVM-verified only — nothing below has run on a
device.** Interactive version: `320 Device Test Matrix` artifact.

**Priority:** P0 = crash / regression, must pass · P1 = core behaviour · P2 = polish / edge cases.
**Result:** mark each PASS / FAIL / BLOCKED / — (not run).

## Preconditions

- Install **3.120.0.320** from the internal track on a **real device** (capture / raw-socket behaviour
  cannot be judged on an emulator).
- Spread across a small phone (~5"), a large phone or foldable, and a tablet; include one old OS
  (Android 7, minSdk 24) and one modern (Android 14+) where possible.
- At least two installed distros — one **with** tcpdump + tshark, one **without** — plus, ideally, a
  saved SSH host for the remote path.
- Exercise each case in **light and dark**, **English and Thai**, and at **default and largest font scale**.
- Have a small `.pcap`, a large one (>200 MB), and a non-pcap / corrupt file on the device for the import tests.
