# TermiNow 3.120.0.314 — Internal

รุ่นทดสอบภายใน (Internal testing) · ไม่ใช่รุ่น production · 2 พ.ย. 2026 · arm64-v8a เท่านั้น

รุ่นนี้ต่อยอดจาก 312 บนสาขา `backup-schedule-cloud` เพิ่มหมวด **Security** ใน Tools Library และแก้พฤติกรรม tmux ของตัวจัดการ Local Linux เพื่อทดสอบบนอุปกรณ์จริงก่อนพิจารณาปล่อยจริง (production ปัจจุบันคือ 304)

## ใหม่ (เพิ่มจาก 312)

- **หมวด "Security" ใน Tools Library:** เพิ่มชิป Security (เฉพาะ distro ในเครื่อง) ที่เปิดหน้ารวมเครื่องมือความปลอดภัย โดยต่อยอดจากแคตาล็อก/คิวติดตั้ง apt ต่อสภาพแวดล้อมเดิม (ไม่เขียนใหม่) — ติดตั้งเครื่องมือทีละตัว ไม่ใช้ metapackage
  - **การ์ดเครื่องมือ + รายละเอียด:** Install / Open, เวอร์ชัน+สถานะ, Update/Uninstall ในเมนู (เมื่อรองรับ), ปุ่มข้อมูล→แผงรายละเอียดพร้อมลิงก์เอกสารทางการ, ป้ายกำกับ (CLI/GUI, ARM64, Requires privileges, Limited support), และสถานะชัดเจน (ยังไม่ติดตั้ง / เข้าคิว / กำลังติดตั้ง / ติดตั้งแล้ว / ล้มเหลว / **ไม่รองรับ + เหตุผลที่นำไปทำต่อได้**)
  - **ความจริงเรื่องความสามารถ:** แผงรายละเอียดอธิบายข้อจำกัดจริง — Nmap TCP connect (-sT) อาจใช้ได้แม้โหมด raw-packet ใช้ไม่ได้; uid 0 ใน PRoot เป็น fake-root ไม่ใช่สิทธิ์เคอร์เนล Android; วิเคราะห์ไฟล์ .pcap ต่างจากจับแพ็กเก็ตสด; โหมด monitor ของ Wi-Fi ขึ้นกับเคอร์เนล/ฮาร์ดแวร์/ไดรเวอร์/สิทธิ์; การติดตั้ง Kali ไม่ได้เปิดใช้สิ่งเหล่านี้โดยอัตโนมัติ
  - **Open (เปิดใช้งาน):** เปิดเครื่องมือในเทอร์มินัลของสภาพแวดล้อมที่เลือก; เครื่องมือที่ต้องมีอาร์กิวเมนต์จะเปิดตัวช่วยคำสั่ง (Nmap = TCP connect, TShark = เลือกไฟล์ .pcap/.pcapng) — ส่งค่าเป็นอาร์กิวเมนต์อย่างปลอดภัย ไม่มี shell injection, **ไม่เริ่มสแกนเองหลังติดตั้ง**
  - **Update/Uninstall:** ผ่านคิว apt เดิม; Uninstall ลบเฉพาะแพ็กเกจที่ TermiNow ติดตั้งและติดตามไว้ (ไม่แตะเครื่องมือเดิมของผู้ใช้หรือ dependency ที่ใช้ร่วมกัน); ไม่ลบ lock file และไม่ kill โพรเซสที่ไม่เกี่ยวข้อง
  - **ระยะไกล (SSH):** แสดงว่ายังไม่รองรับพร้อมคำอธิบาย — **ไม่มีปุ่ม "Run on SSH" ปลอม**
- **Local Linux — ไม่มี fallback เงียบ ๆ เรื่อง tmux:** เมื่อเปิด "Use tmux" ของ distro แต่ยังไม่ได้ติดตั้ง tmux ในนั้น การกด "+ เซสชันใหม่" จะถามให้เลือกชัดเจน — **ติดตั้ง tmux** / **เปิดโดยไม่ใช้ tmux** (ครั้งนี้ครั้งเดียว ไม่เปลี่ยนค่าที่บันทึกไว้) / ยกเลิก — แทนที่จะเปิดเชลล์ธรรมดาให้เองเงียบ ๆ

รุ่นนี้ยังรวมทุกอย่างจาก 312 ด้วย: Network Discovery (ออกแบบใหม่), Local Linux (ออกแบบใหม่ — สวิตช์ Use tmux ต่อ distro / Select OS แบบการ์ด / ส่วนจัดการ tmux session), เครื่องมือความปลอดภัย + จับแพ็กเก็ต (Kali/Linux), ตัวดู VNC ในตัว, และสำรอง/กู้คืน (คลาวด์ + ตั้งเวลา)

## สถานะการตรวจสอบ

- **ตรวจแล้ว (ระดับ build):** คอมไพล์ผ่านทั้งสอง flavor; unit tests ที่เกี่ยวข้องผ่าน (Security 16, Capture 12, ToolInstaller 30, Queue 6, LaunchPlan/Launcher ฯลฯ — 0 ล้มเหลว); ไลบรารีเนทีฟ arm64-v8a ครบทั้ง 4 (libtermux, libtermux-bootstrap, libproot-loader, libterminow-rdp); เซ็นด้วย upload key; Play ยอมรับ bundle และปล่อยบน internal track แล้ว
- **ยังไม่ได้ตรวจบนอุปกรณ์จริง:** UI และพฤติกรรมจริงทั้งหมด (บิลด์บน proot aarch64 ไม่มีอุปกรณ์จริง) โดยเฉพาะ: หมวด Security (ป้ายกำกับ/รายละเอียด/Open composer/Update/Uninstall), การติดตั้งเครื่องมือจริงผ่าน apt, กล่องเลือก Install tmux / Open-without-tmux, และการจัดการ tmux session; ดูรายการตรวจบนอุปกรณ์ท้ายหมายเหตุ 312
- arm64-v8a เท่านั้น (ยังไม่รวม x86_64 ในบิลด์นี้)

## หมายเหตุด้านความปลอดภัย

- เครื่องมือความปลอดภัยมีไว้สำหรับการทดสอบที่ได้รับอนุญาตเท่านั้น (ข้อความช่วย: "ใช้เฉพาะกับระบบที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ทดสอบ"); ไม่อัปโหลดเนื้อหาที่จับได้ไปยัง AI/บุคคลที่สามโดยอัตโนมัติ
- ไม่ใช้ตัวติดตั้งแบบ curl-to-shell ที่ยังไม่ตรวจสอบ; ติดตั้งจากแพ็กเกจของ distro; ไม่อัปเกรดทั้งระบบซ้ำ ๆ; ไม่ทับ shell profile หรือไฟล์ปฏิบัติการของ upstream
- uid 0 ใน PRoot ไม่ใช่สิทธิ์เคอร์เนล Android — ไม่สรุปว่ามี raw socket จาก uid=0
- การ Disconnect/stop จัดการเฉพาะ session นั้น ไม่ปิด SSH/SFTP หรือ session อื่นของ Ubuntu
