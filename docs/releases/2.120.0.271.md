# TermiNow 2.120.0.271 — Internal

รุ่นทดสอบภายใน (Internal testing) · ไม่ใช่รุ่น production · 28 ต.ค. 2026

รุ่นนี้รวมงานฟีเจอร์ใหม่ที่ยังไม่เคยอยู่ใน production (270) เพื่อให้ทดสอบบนอุปกรณ์และเซิร์ฟเวอร์จริงก่อนพิจารณาปล่อยจริง

## ใหม่

- **Virtual Labs — Proxmox VE:** เพิ่มการเชื่อมต่อ Proxmox VE ผ่าน REST API ด้วย API token, ตรวจสอบใบรับรอง TLS (self-signed เชื่อถือได้เฉพาะหลังยืนยัน fingerprint SHA-256), เก็บ token secret แบบเข้ารหัสด้วย Android keystore, แสดงรายการ nodes/VM/LXC พร้อมสถานะ, สั่ง start/shutdown/reboot/stop พร้อมยืนยันและติดตามสถานะงาน, และเปิด Web UI
- **Virtual Labs — Docker:** จัดการ Docker ผ่าน SSH ของโฮสต์ (คง SSH host-key verification), ตรวจการเข้าถึง docker, แสดงคอนเทนเนอร์, start/restart/stop พร้อมยืนยัน, ดู logs, ตรวจพบ Docker Compose และเปิดเชลล์ในคอนเทนเนอร์แบบโต้ตอบ (`docker exec -it`) อาร์กิวเมนต์ถูก escape กันการแทรกคำสั่ง
- **Virtual Labs — Card UI:** เปลี่ยนหน้า Virtual Labs เป็นการ์ด 5 รายการ คง MikroTik CHR, Linux VM และ VMware ESXi เดิม
- **แก้ไขไฟล์ระยะไกลผ่าน SFTP:** เปิด/แก้/บันทึกไฟล์ข้อความบนโฮสต์ SSH ในแอป พร้อม draft, ตรวจความขัดแย้ง และเลือก encoding
- **แถบนำทางแบบ responsive:** แถบด้านข้าง 3 สถานะ (เต็ม / ไอคอนอย่างเดียว / ซ่อน) ปรับตามความกว้างหน้าต่างจริง, จำสถานะต่อขนาดจอ, บนมือถือเปิดเป็น overlay drawer (แตะพื้นหลัง/Back/เลือกเมนูเพื่อปิด) และมีปุ่มเมนูที่เข้าถึงได้ทุกหน้า

## สถานะการตรวจสอบ

- **ตรวจแล้ว:** คอมไพล์ผ่านทั้งหมด; unit tests ของ Proxmox (11) และ Docker (5) ผ่าน
- **ต้องตรวจบนเซิร์ฟเวอร์จริง:** การเรียก Proxmox REST, การติดตามงาน, การดึง/เชื่อถือใบรับรอง, คำสั่ง Docker ผ่าน SSH และ exec PTY — ยังไม่มีเซิร์ฟเวอร์ทดสอบ จึงยังไม่ได้รัน integration test
- **ต้องตรวจบนอุปกรณ์จริง:** พฤติกรรมแถบนำทาง/overlay ที่ความกว้าง 360 / 600 / 800 / 1280 dp และการพับ/กาง/หมุน

## หมายเหตุด้านความปลอดภัย

คง TLS verification + fingerprint pinning, SSH host-key verification, escape อาร์กิวเมนต์ก่อนส่งผ่าน SSH, เก็บ secret แบบเข้ารหัสและไม่บันทึกลง log/plain-text, ไม่เปิด Docker TCP API แบบไม่มี auth และไม่แก้ไขสิทธิ์/ติดตั้งบนโฮสต์โดยอัตโนมัติ
